# oblige
English translation patch for Nintendo Switch version of `Select Oblige`. Based on the Re-Translation Patch by momo-mods.

# Notes 
* Certain censored CGs have been replaced with their uncensored versions from the PC patch, though no R18 content has been added.

# Installation
1.  Download `root.pfs.050` from the [Releases](../../releases) page.
2.  Create the path `/atmosphere/contents/0100555024734000/romfs` on your SD card.
3.  Copy `root.pfs.050` into the folder created in step 2.
4.  Launch the game.
